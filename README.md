# Blue Sea Fishery [BlueSeaFisher] - English Translation

A full English translation of **蓝海渔业 (Blue Sea Fishery)**, a Chinese faction mod for [Starsector](https://fractalsoftworks.com/) by **Qingzhuo Wuyue (清酌巫月)**.

All credit for the mod itself goes to the original author and team. This repository only hosts the English translation.

> *"Built on ballistic firepower, backed by carrier groups and combined operations - we're here to carve out a stretch of sea in this sector where we can slack off (and maybe do a little fishing)!"*

## About the mod

Blue Sea Fishery was once a quiet fishing colony that grew rich on Gate trade. When the Gates went dark, it was cut off from the rest of the Sector, survived on its own oceans, and quietly sat out both AI Wars. Now it is starting to draw the Persean Sector's attention - with a navy of fish, crabs, whales and very large guns.

- A full playable faction with its own star systems, markets, patrols and Nexerelin support
- A complete fleet from frigates to battleships, plus the Tridacna mobile fortress and the Humpback Whale cruise liner
- Ballistic-heavy weapons named after birds, bugs and snakes
- Carrier doctrine with 18 fighter wings, including recon craft that dock with the Osprey Fusion Framework to buff their carrier
- The Battlefield Link Network, which lets Blue Sea Fishery ships strengthen each other in combat
- Unique hullmods, a bar event with the Sigma-type AI core, and three missions

## Requirements

- LazyLib
- GraphicsLib
- MagicLib
- Optional: Nexerelin

All four are available on the [Fractal Softworks forum](https://fractalsoftworks.com/forum/).

## Installation

1. If you have the Chinese version installed, **delete its `BlueSeaFisher` folder first** - both versions use the same mod ID.
2. Unzip the release into `Starsector/mods/`.
3. Enable **Blue Sea Fishery [BlueSeaFisher]** in the launcher.

Start a new save if you are switching over from the Chinese version.

## What's translated

Everything: ship, weapon, hullmod, fighter and ship system names and descriptions, the codex, tooltips, rules and dialogue, the faction file, missions, skins, variants, the Nexerelin config, and the text hardcoded inside the mod's `.jar`.

Translation fixes included in this release:

- Renamed a music file whose special character crashed the game on English systems
- Removed stray `{ }` brackets that appeared around numbers in tooltips
- Corrected the German Shepherd recon wing's description to match its actual flux dissipation bonus

## Known issues (from the original mod)

- The "Great Sea Battle" mission can leave the background stuck on the sea backdrop. Restarting the game fixes it.
